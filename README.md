# 📝 Lista de Tareas en Python

Aplicación de consola para gestionar una lista de tareas: permite ver, agregar y eliminar tareas mediante un menú interactivo.

## 🚀 ¿Qué hace?

- **Ver tareas**: muestra todas las tareas guardadas (o avisa si la lista está vacía)
- **Agregar tareas**: añade una nueva tarea a la lista
- **Eliminar tareas**: quita una tarea existente, validando que realmente exista
- **Salir**: cierra el programa

## 🛠️ Tecnologías

- Python 3

## ▶️ Cómo ejecutarlo

1. Clona este repositorio o descarga el archivo `tareas.py`
2. Abre una terminal en la carpeta del proyecto
3. Ejecuta:

```bash
python tareas.py
```

4. Sigue las instrucciones del menú (elige una opción del 1 al 4)

## 📸 Ejemplo de uso

```
----------------
Menu de opciones
----------------
Quieres ver tareas (1), agregar(2), quitar tareas(3) o salir (4)
Elije una opcion: 2
----------------
Que tarea quieres asignar: Estudiar Python
----------------
```

## 📚 Lo que aprendí con este proyecto

- Manejo de **listas** en Python (`append`, `remove`, `in`, `len`)
- **Bucles** `while` y `for` para menús interactivos y recorrido de datos
- **Condicionales** `if / elif / else` para controlar el flujo del programa
- **Funciones** para organizar el código y hacerlo más legible
- Validación básica de entradas del usuario
